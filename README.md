# Renovare — Clínica de Estética Avançada & Bem-Estar

Landing page de alta fidelidade e performance desenvolvida para a **Clínica Renovare** (Betim, MG).

## 🚀 Tecnologias

- **React 19** + **TypeScript**
- **Vite**
- **GSAP 3** (`@gsap/react`, `ScrollTrigger`)
- **Three.js** (Modelo procedural 3D do lírio Renovare com shaders e animação orgânica)
- **Lucide Icons**
- Arquitetura CSS modular anti-slop de alto desempenho

## 📦 Como Rodar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/faznadoze/renovare.git
cd renovare
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Para gerar o build de produção:
```bash
npm run build
```
